# Mission 3 Reflection

Completing the Multi-Cloud Explorer activity changed the way I look at cloud platforms. Instead of viewing AWS, Microsoft Azure, and Google Cloud as three versions of the same service, I learned that each platform has a different set of strengths. **Google Cloud impressed me the most** because its services for artificial intelligence, data processing, and Kubernetes feel closely connected. Services such as Vertex AI, Compute Engine, Cloud Storage, and Google Kubernetes Engine show how one platform can support a project from development to deployment.

At the same time, the activity showed me that the three providers are similar in many important areas. All of them provide virtual machines, object storage, virtual networking, identity and access management, managed databases, and Kubernetes services. They also use global infrastructure to improve availability and allow organizations to deploy resources closer to users.

I also learned that the “best” cloud provider depends on the business requirement. A university already using Microsoft 365, Windows Server, and Active Directory may gain more value from Azure, while an AI-focused company may prefer Google Cloud. A global e-commerce company may choose AWS because of its broad service portfolio and mature scaling and content-delivery options. Cost, existing technology, staff skills, security, location, scalability, and application design all affect the final decision.

Acting as a Cloud Solutions Consultant helped me practice making recommendations instead of simply listing features. I had to connect technical services to real business problems and explain why one option fit a scenario better than another. My GitHub Cloud Computing Portfolio also became more organized because this mission added structured research, comparison tables, evidence screenshots, recommendations, and a Linux investigation. The repository now shows not only commands and definitions, but also my ability to document and justify cloud architecture choices.
